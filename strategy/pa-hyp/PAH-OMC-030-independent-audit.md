# PAH-OMC-030 independent and hostile audit

The independent audit reads the four result cards and the preregistered source
pins directly. It does not import the primary verifier or any generated index.

## Independent findings

1. R-514 is a fixed-`n` result and explicitly lists the varying-space `U_n`,
   N2b liminf/recovery, N2c/N4 boundary escape, N2d minimal identification and
   anchored `n` convergence as missing.
2. R-510's local pullback is not asserted to extend to a bounded map on the
   completed finite `L2(nu_n)` space. Its terminal-square convention differs
   from the split transfer prefix outside the fixed local core.
3. R-511 identifies the same cylinder algebra and original generator, but only
   gives the sampled local pre-form and not a finite-to-common-space temporal
   realization.
4. R-568 is conditional on a semigroup already existing on the same `H` and
   extending `A`; its own non-claims exclude original finite-semigroup
   convergence.

The four sources are therefore compatible as prerequisites, but jointly
insufficient for the displayed `n` limit. No source-authorized counterexample
was found. The independent verdict is `HOLD_FOR_EVIDENCE`.

## Hostile controls

The audit rejects each of the following invalid promotions: treating a local
cylinder pullback as a full `U_n`; replacing the terminal unsplit square by
split cells; using fixed-`n` compact constants as an `n`-uniform rate bound;
using the R-568 target tail as a finite-state tail; and inferring existence of
a finite limit from uniqueness of a possible extension. It also rejects any
physical interpretation of the external Markov time.

The hostile verdict is `HOLD_FOR_EVIDENCE`, not `DISPROVED`, because these are
missing hypotheses rather than an exact failure of the frozen PAH model.
