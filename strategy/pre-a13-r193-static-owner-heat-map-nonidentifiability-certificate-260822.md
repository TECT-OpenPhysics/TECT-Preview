# R-193 / static owner to heat-map non-identifiability witness

## 1. Scope

R-193 is a T0, claim-nonbearing interface audit following R-192.  It asks a
sharp question: can the pinned A1 static production functional and A7 static
covariance-normal data determine the heat/root map required by the A13
production owner?

The answer is no at the present interface.  A1 fixes a deterministic finite
functional and A7 fixes covariance-normal composite definitions, but neither
authority supplies a heat generator, a filtration, a raw-current spatial
intertwiner, or a once-owned `q_k` ledger.  R-136 and R-125 explicitly retain
the latter production flags as false.

## 2. Exact witness

The Lean entrypoint `verification/lean/Tect/R193.lean` defines a two-coordinate
static inverse pair `(h,c)=((1,2),(1,1/2))` and two diagonal contractions:

`D_A(x,y)=(x/2,y/4)` and `D_B(x,y)=(x/4,y/2)`.

Both preserve zero, both have positive factors strictly below one, and both
are compatible with the same static inverse relation `h_i c_i=1`.  They are
distinct and reverse the relative decay order.  Thus the static data do not
select a unique heat/root map.  This is an exact finite interface witness, not
a claim that either map is the A1 production dynamics.
