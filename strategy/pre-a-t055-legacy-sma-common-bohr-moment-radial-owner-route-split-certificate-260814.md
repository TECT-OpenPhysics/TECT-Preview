## 3. Signed-mode convention and exact moments

Let `S=-S` be a finite signed support with no zero vector and let

```text
phi(x) = c sum_(k in S) exp(i k.x),       c real.
```

For the Bohr mean `M_B`, define

```text
N_(2m)(S) = #{(k1,...,k_(2m)) in S^(2m): k1+...+k_(2m)=0}.
```

Orthogonality gives, without a finite-box approximation,

```text
M_B(phi^2) = N2 c^2,
M_B(phi^4) = N4 c^4,
M_B(phi^6) = N6 c^6.
```

Writing `I=M_B(phi^2)`, the normalized ratios are

```text
K4 = N4/N2^2,        K6 = N6/N2^3.
```

Math396 instead writes one amplitude `a_cos` per positive cosine direction:

```text
phi(x) = sum_(j=1)^n a_cos cos(q_j.x).
```

The signed Fourier coefficient is `c=a_cos/2`, `N2=2n`, and therefore

```text
I = N2 c^2 = n a_cos^2/2.
```

This proves the amplitude firewall `a_cos=2c` and removes the apparent factor
four discrepancy between the Math396 and R-169 v1.3 conventions.
