# EXP-001065 / finite Gibbs invariance and conditional OS intertwiner

## Decision

The exact finite input needed for an orbit-contractivity argument is not an
arbitrary fixed state.  It is the Gibbs state generated by the same finite
Hamiltonian.

Let (H=H^*) be finite dimensional, (U_t=exp(-itH/\hbar)), and

\[
 \rho_\beta=Z^{-1}\exp(-\beta H),\qquad
 N_\beta(X)^2=\operatorname{Tr}(\rho_\beta X^*X)
                    +\operatorname{Tr}(\rho_\beta XX^*).
\]

Functional calculus gives ([\rho_\beta,U_t]=0).  Therefore finite trace
cyclicity gives, separately for the two terms,

\[
 N_\beta(U_t^* X U_t)=N_\beta(X).
\]

For the exact two-level fixture with Boltzmann ratio (q=1/2),
(\rho=\operatorname{diag}(2/3,1/3)), (U=\operatorname{diag}(1,-1)), and

\[
 X=\begin{pmatrix}1&2\\3&4\end{pmatrix},
\qquad
 U^* X U=\begin{pmatrix}1&-2\\-3&4\end{pmatrix},
\]

both squared two-sided seminorms are exactly (25).  The primary SymPy lane,
the independent Fraction lane, and Lean R247 reproduce this equality.

## Conditional OS transfer

This finite theorem transfers to the fixed-beta OS carrier only if all of the
following are proved for the actual Q3 finite members: a seminorm-isometric map
from the finite word core, intertwining with one common OS time action,
compatibility on common local words, and exhaustion-independent convergence (or
a direct Cauchy theorem).  Under those hypotheses,

\[
 \|\alpha_t^{OS}\Phi_\Lambda(X)\|_{\beta,#}
 =N_{\beta,\Lambda}(\alpha_t^\Lambda X)
 =N_{\beta,\Lambda}(X)
 =\|\Phi_\Lambda(X)\|_{\beta,#}.
\]

This is a conditional interface statement, not the missing Hamiltonian-to-OS
identification.
