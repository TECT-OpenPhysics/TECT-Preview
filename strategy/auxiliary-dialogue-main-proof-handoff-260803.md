## 1. Purpose

This record makes stable strategy from an auxiliary, non-proof dialogue
available to the main proof lane without treating chat as mathematical or
physical evidence. The repository remains the only authority. A conversational
idea enters the main lane only after it is classified and written to the
appropriate tracked surface.

The main lane already reads the latest `explorations/log.jsonl` decisions and
`TODO.md` at session entry. This handoff is therefore routed through those
surfaces and cites the underlying strategy authorities.

## 2. Routing contract

| Auxiliary-dialogue content | Canonical destination | Main-lane use |
|---|---|---|
| Founding ontology, research direction, or candidate family | `strategy/` note | Hypothesis generation and test design only |
| Stable proof-route choice, obstruction, or resume condition | append-only `explorations/log.jsonl` | Route selection; never theorem authority |
| Actionable priority or experiment | `todo/todo.json` -> generated `TODO.md` | Scheduling and ownership |
| Formal analytic or numerical result | claim note, run artefact, manifest, result or negative ledger | Evidence at its registered scope |
| Tier, gate, vacuum, phase, or physical verdict | claim card or negative registry plus required atomic records | May be stated only after the authority is written |

Raw chat, intuition, analogy, and private reasoning are not imported. Only a
finite question, discriminator, boundary, and next action are retained.

## 4. How the main proof lane should consume results

Every new Sector-A result should receive two independent labels:

- **internal mathematical effect:** what it proves about a fixed functional;
- **Pre-A selection effect:** whether it changes a preregistered discriminator
  for candidate M1 or another candidate.

Most A13 results have the first effect only. They do not acquire a phase or PDE
verdict through this handoff.

Conversely, if a certified same-functional result shows that the pinned M1
functional has only the trivial global minimiser, cannot retain finite-wave-
number order, or fails the common reference-state comparison within a declared
parameter and continuum scope, the main lane should cross-link that result to
T-052 and T-054 as candidate-selection evidence. It must not generalise that
scoped result into a no-go for all emergent-structure models.

If a result instead establishes a nontrivial stable phase, it still does not
identify light, mass, time, or gravity. It advances only the corresponding
arrow of the Pre-A structural chain; later arrows retain their own falsifiers.
