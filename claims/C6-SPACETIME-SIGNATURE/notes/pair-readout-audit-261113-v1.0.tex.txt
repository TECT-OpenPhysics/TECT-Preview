\section{The independent-readout test}
For a native instrument setting $j$, the complete calibrated effect would
be $E_j=\mathcal I_j^*(M_j)$, including pulse2 and all later detection
operations. In a closed unitary description this reduces to
$U_{\#2}^\dagger M_jU_{\#2}$ only if $M_j$ already includes the full
post-pulse chain. Endpoint populations after independently calibrated
analyzers can legitimately reveal coherence; population differentiation
or refitting the same unknown state/analyzer phase is not independent.
Changing the evolution time generally changes the state and is not
tomography of a single frozen pre-readout preparation.

For clarity, the following standard finite-dimensional algebra is a
\emph{conditional diagnostic}, not a model of the native continuum. On the
reference basis $|A\rangle=|2,0\rangle$, $|M\rangle=|0,1\rangle$,
\[
 \rho=(I+r\cdot\sigma)/2,\quad B=b^\dagger a^2=\sqrt2|M\rangle\langle A|,
 \quad C=\operatorname{tr}(\rho B)=(r_x-ir_y)/\sqrt2.
\]
With $H_{\rm pair}=gB+\bar gB^\dagger$, the reference number flux is
$\dot N_a=-4\Im(gC)/\hbar$. Thus $\Im C$ alone is a current quadrature
only after anchoring the phase convention of $g$. A joint basis rephase
of $C$ and $g$ is a coordinate change, not a physical-current ambiguity.
No identification with EXCH coefficients or physical time is imported.

If calibrated effects give $m_j=e_{0j}+e_j\cdot r$, write $y=Ar$ for
$y=m-e_0$. A target $t=a^Tr$ is identifiable exactly when
\[
 \ker A\subseteq\ker a^T\quad\Longleftrightarrow\quad
 a^T\in\operatorname{rowspan}A.
\]
Sufficiency follows from $A^T\beta=a$. Necessity follows by two small
opposite perturbations along a null direction in the state's relative
interior. Known population constraints must be included in the admissible
difference space. Full tomography is not necessary: a calibrated pure-$y$
effect can suffice for the minimum target. Conversely, equal populations
and calibrated $x,z$ effects do not distinguish $(I\pm\sigma_y)/2$,
whose pair quadratures and a calibrated $y$ response differ.
For a nonconvex preparation class use its actual admissible differences,
not an unjustified linear enlargement. Unit rows in the primary rank
controls denote centered/rescaled Pauli expectations, not raw probability
effect vectors; the independent calculation uses actual projector effects.

For an analyzer with unknown orientation relative to fixed $g$,
\[
 m_\phi=\tfrac12[1+r_x\cos(\phi+\delta)+r_y\sin(\phi+\delta)].
\]
Rotating $r_\perp$ by $\alpha$ and replacing $\delta$ by
$\delta+\alpha$ leaves all nominal-setting probabilities unchanged while
the fixed-$g$ current can change. This diagnoses missing relative analyzer
calibration, not impossibility of calibration or of the native experiment.

\section{Errors and the reserved response}
If $A^T\beta=a$, then $\hat t=\beta^Ty$ and
$\operatorname{Var}\hat t=\beta^T\Sigma\beta$. For a known holdout row
$e_h=A^T\beta_h$,
\[
 \operatorname{Var}(m_h-\hat m_h)=\Sigma_{hh}
 +\beta_h^T\Sigma_{\rm train}\beta_h
 -2\beta_h^T\Sigma_{{\rm train},h}.
\]
Neither covariance diagonality nor independence is assumed. Independently
justified calibration is not presumed statistically uncorrelated. It has
additional joint sensitivity and higher-order remainder terms. Under
independently justified effect bounds
$|\Delta e_{0j}|+\|\Delta e_j\|\le\eta_j$, a fixed linear estimator
has an error contribution bounded by $\sum_j|\beta_j|\eta_j$ on the
Bloch ball. This is not a measured native bound. Covariance alone is not
a guaranteed interval without a declared coverage rule or tail bound.

Loss outcomes and raw normalizations must be retained. Renormalizing by
postselected survival generally makes the signal nonlinear in the initial
state and invalidates a linear-effect rank test unless separately justified.
The actual source has shot-number variation, undetected channels and
state/readout contamination. These cannot be replaced by an exact fixed-$N$
preparation or a zero leakage/error assumption.

The published pulse2 fall-time settings 11 and 159 microseconds are frozen
as a base sensitivity case and a reserved retrospective case. Their
published phase fits are not independent analyzer calibration. The 159
setting has not been fitted here, but its outcome was already inspected;
it receives no prospective credit. No phase prediction, holdout residual,
confidence interval or empirical PASS is computed without the missing
instrument/error/outcome packet. This is NOT\_EXECUTED, not a failed
