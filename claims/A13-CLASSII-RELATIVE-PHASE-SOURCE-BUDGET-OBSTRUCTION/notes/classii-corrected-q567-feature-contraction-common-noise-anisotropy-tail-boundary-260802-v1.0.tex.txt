\section*{5. Finite-set Douglas theorem}
\hypertarget{section-5-douglas}{ }

Let $h_1,\ldots,h_N$ be any finite admissible endpoint family and set
\[
 (G_Y)_{ab}=\ip{\cY(h_a)}{\cY(h_b)},\qquad
 (G_U)_{ab}=\ip{\cU(h_a)}{\cU(h_b)}.                \tag{5.1}
\]

\textbf{Theorem 5.1.}  The following are equivalent:
\begin{enumerate}
\item $G_U\preceq G_Y$;
\item there is a contraction
      $C:\overline{\operatorname{span}}\{\cY(h_a)\}\to\cH_U$
      with $C\cY(h_a)=\cU(h_a)$ for every $a$;
\item for every coefficient vector $c$,
\[
 \left\|\sum_ac_a\cU(h_a)\right\|^2
 \leq
 \left\|\sum_ac_a\cY(h_a)\right\|^2.              \tag{5.2}
\]
\end{enumerate}

\textit{Proof.}  Write $Yc=\sum_ac_a\cY(h_a)$ and
$Uc=\sum_ac_a\cU(h_a)$.  The Gram inequality is exactly
$\|Uc\|\leq\|Yc\|$.  Hence $Yc=0$ implies $Uc=0$, so
$C_0(Yc)=Uc$ is well-defined and contractive on $\Ran Y$ and extends to its
closure.  Conversely, $U=CY$ and $\|C\|\leq1$ imply
$U^*U\preceq Y^*Y$.  \hfill$\square$

The optimal finite-family constant is
\[
 \rho_*^2=
 \lambda_{\max}\!\left(G_Y^{\dagger/2}G_UG_Y^{\dagger/2}\right),          \tag{5.3}
\]
provided $\Ker G_Y\subseteq\Ker G_U$; otherwise $\rho_*=\infty$.  If
$\rho_*<1$ then
\[
 c^*(G_Y-G_U)c\geq(1-\rho_*^2)c^*G_Yc.             \tag{5.4}
\]

This theorem is strictly stronger than checking every endpoint energy.
For example, take $G_Y=\Id_2$ and
\[
 G_U={9\over16}\begin{pmatrix}1&1\\1&1\end{pmatrix}.                     \tag{5.5}
\]
Each diagonal of $G_Y-G_U$ is $7/16>0$, but its eigenvalues are
$-1/8$ and $1$, while $\rho_*^2=9/8>1$.  Both certificates reproduce this
mixed-only obstruction exactly.
