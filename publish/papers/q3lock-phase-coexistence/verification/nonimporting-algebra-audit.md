## Exact objects and comparison contract

Starting from manuscript eq:potential, the checker constructs

    U(q) = (r/2) sum_i q_i^2 + (g/4) sum_i q_i^4
           + (lambda/4) sum_edges (q_i-q_j)^2 (q_i^2+q_j^2).

Q3 edges are generated by one-bit differences of binary vertex indices.
The number of vertices and their common degree are computed from that graph.
Hamiltonian coefficients are model inputs. The printed right-hand-side
coefficients used for comparison are explicitly labelled manuscript test
oracles; they are not substituted into the differentiation calculation.

The derivative along the normalized collective unit vector is represented
without irrational coefficients: its second derivative is
(sum_i partial_i)^2 U / 8. The fourth derivative uses division by 8^2.
Each spatial bond is separately checked to be unchanged by common translation.
Summing these local identities gives the displayed finite-volume algebra
with its 1/V factor, provided the same normalized collective vector is used.
The code does not construct or certify the corresponding operator domains.

Every compared polynomial is stored as its complete rational coefficient
dictionary. Residual dictionaries must be empty. No floating tolerance,
root approximation, Watson-integral estimate or fitted physical value is used.

## Conditional moment certificate

Let s, d and M denote expectations of S_0, D_0^int and Q_0^2 respectively,
not pointwise coordinates. Set

    B = r + (3g s + lambda d)/8.

The checker verifies the exact identity

    3(g+lambda) M + r
      = 3(g+lambda)(M-s/8) + B + (lambda/8)(3s-d).

To conclude M >= -r/[3(g+lambda)] one still needs all three separately
reviewed analytic premises:

- M-s/8 >= 0 from zero-source parity and loop FKG;
- B >= 0 from the translated-form Gibbs/Jensen argument;
- 3s-d >= 0 from the Q3 graph expansion and nonnegative edge expectations.

For g, lambda > 0 the displayed weights are positive. The identity alone
does not supply these expectation inequalities. An alternating-sign cube
vector is a hostile control: its pointwise D exceeds 3S. This is consistent
with the manuscript's explicit expectation-only statement, not a new
counterexample to its phase claim.

## Threshold algebra and scope

Write t=tanh(x) with x>0, theta=theta_Q>0 and m,c>0. Conditional on the
analytic root equation beta=4m theta x t, the script checks

    2 beta c theta t - x I3 = x(8cm theta^2 t^2-I3).

Division by positive x yields the manuscript's threshold identity for
delta=theta t/x-I3/(2 beta c). The code does not prove monotonicity,
existence of x, evaluation/finiteness of I3, the Griffiths cusp lemma or
the DLR state construction. I3 is a formal symbol, not a numerical estimate.
No conclusion about phase absence follows outside the sufficient regime.

## Adversarial review

1. Sign: the checker differentiates minus the energy for log density.
   Reversing the sign is a rejected polynomial mutant. UPHELD.
2. Convention: normalized collective differentiation divides by the computed
   component count. Extra hbar squared, omitted locking curvature and a
   halved threshold amplitude are rejected. UPHELD.
3. Domain: a coordinate polynomial identity is not positivity of its Gibbs
   expectation. The conditional deficit certificate exposes the missing
   analytic premises; the alternating vector rejects a pointwise shortcut.
   UPHELD.
4. Limits and convergence: coefficient algebra has no discretization or
   floating convergence error, but it proves no volume, time-mesh or
   coordinate-cutoff limit. UPHELD.
5. Units: no new physical unit is introduced. The Hessian is not the momentum
   double commutator; that latter identity includes hbar squared. The threshold
   cancellation retains beta, m, c and theta as separate formal inputs.
   UPHELD; full unit conventions remain a manuscript-review obligation.
6. Hardcode masking: the physical polynomial is expanded and differentiated
   before comparison with the separately printed test oracles. Residual
   coefficients and hostile mutants are recorded. Ring tests include an
   intentionally broken differentiator. UPHELD.
7. Independence: there is no repository-code import, but same-task authorship
   and common manuscript inputs can share conceptual errors. External review
   and any required proof-kernel formalization are not replaced. UPHELD.
