# Q3LOCK: request for independent mathematical review

## Purpose

We request a critical, location-specific review of Phase Coexistence in an
Eight-Component Q3-Locked Quantum Anharmonic Crystal, by Jusang Lee. This is a
review edition of research manuscript v0.1.38, not a request for endorsement.
The accompanying PDF exists to make external assessment possible. It does not
represent a signed external review or a completed journal submission.

## The precise object to assess

The manuscript concerns a fixed-spacing, three-dimensional quantum anharmonic
lattice with eight real components at each site and a non-radial quartic
interaction on the internal cube graph Q3. The source couples to the normalized
collective direction. Its proposed conclusion is a conditional composition:
under the stated analytic inputs and explicit low-temperature sufficient regime,
the infinite-volume pressure has a strict source cusp and there are at least
two distinct, parity-related, zero-source tempered Euclidean DLR states.

The author does not assert an all-parameter phase theorem, a necessary phase
boundary, pure or extremal states, a complete phase classification, real-time
KMS dynamics, a ground-state gap, a continuum limit, a physical vacuum,
cosmology, or the closure of a TECT sector. The result remains R-497, T0 and
non-claim-bearing in the research registry. No priority claim is made.

## What would make your review especially useful

For the mathematics, identify a valid proof, a missing hypothesis, an unjustified
limit, or a counterexample at an exact equation or lemma. Please distinguish
finite computational identities from infinite-volume and unbounded-operator
arguments. For the literature, identify the exact theorem and assumptions if
an existing result already subsumes this model and conclusion. A broad title
or a similar scalar/radial model is not by itself a subsumption decision.

Partial reviews are welcome. Please identify the rows you actually reviewed
and leave every other row NOT REVIEWED. A refusal to certify a step is useful
evidence. We do not request a predetermined positive conclusion.

## Suggested reviewer profiles

One reviewer with expertise in mathematical statistical mechanics, Euclidean
Gibbs/DLR measures, quantum anharmonic crystals and thermodynamic limits can
assess the main chain. A complementary reviewer with expertise in unbounded
operator forms, infrared bounds and correlation inequalities can examine the
collective/Falk-Bruch and reflection/FSS blocks. A specialist familiar with
anisotropic vector lattice models should assess novelty and subsumption.

These are expertise criteria, not selected people. No reviewer has been
contacted by this packaging operation. Conflicts of interest and availability
must be checked before an invitation. An email reply with verifiable attribution
and a clear snapshot identification is acceptable project evidence; a specific
signature technology is not required.

## Efficient reading route

Start with the abstract, model dictionary and conditional main theorem. Then
check the manuscript's imported-source comparison and nonclaims. Use the A1-A23
cards in this guide to select a proof block. The archive contains the full
theorem-applicability audit, imported-source ledger, literature comparisons,
proof-audit document and the original independent-review matrix.

The research snapshot retains older version and PDF-DEFERRED notices for exact
replay. The 2026-09-08 review-distribution authorization supersedes the PDF
deferral only; it does not supersede mathematical or literature review gates.
The PDF's review-edition source is a presentation derivative, not an audited
replacement of the original scientific text. The manifest records both hashes.

## Reproduction and its limits

Extract the complete archive into a writable directory. First run the included
verify-package.py script with Python to check every archive member against the
manifest. Next enter research-snapshot and run the read-only integrated replay
command listed in the archive README. Python and SymPy are needed; the tested
runtime and dependency versions are recorded in the build report. No source
PDF download, Git checkout, TeX engine or network request is needed for that
diagnostic replay. TeX is needed only if you choose to rebuild the manuscript.

The replay checks registered finite diagnostics, source identities, assertion
coverage and preserved historical output bytes. It is not a formal proof
checker for the analytic theorem and does not provide external sign-off.

## Return format

Use review-response.md. State your name, affiliation if applicable, date,
distribution identifier, manuscript hash, expertise and conflicts. For each
reviewed A-row give PASS, PASS WITH REPAIR, FAIL or NOT REVIEWED, the precise
location, your reason and any affected downstream statements. For repairs,
provide replacement text or an explicit missing proposition. State separately
whether existing literature subsumes the claim, partially overlaps, or remains
unresolved, with exact theorem numbers and hypotheses.
